14 practical guides
CPU / 01

What a CPU actually does

The processor runs game logic, application instructions, background tasks, and system work. Core count and clock speed both matter, but neither tells the whole story.

What to compare

  • Exact model and generation, not just “Core i7” or “Ryzen 7”
  • Single-core performance for many games and multi-core capacity for heavy workloads
  • Socket, motherboard support, BIOS version, and power requirements

A newer midrange CPU can outperform an older high-tier model. Compare actual model-level results from independent reviews.

GPU / 02

How to compare graphics cards

The GPU usually has the biggest effect on gaming performance, especially at higher resolutions. Model names alone can be misleading across generations.

Check these details

  • Independent benchmarks at your target resolution
  • VRAM capacity and memory bandwidth for the games you play
  • Power draw, card length, thickness, and required connectors
  • Ray tracing and upscaling support if those features matter to you

Compare the exact card model and test settings. Avoid relying on a single synthetic score.

GPU / 03

What VRAM means

Video memory stores textures, frame buffers, and other data the graphics card needs quickly. Higher resolutions and detailed textures can increase memory use.

Useful checks

  • Look at game benchmarks that report memory use and frame-time behavior
  • Consider your resolution and texture settings
  • Do not treat VRAM capacity as a direct measure of GPU speed

A faster GPU with less memory may still outperform a slower GPU with more memory in many games.

CPU + GPU / 04

Understanding bottlenecks

A bottleneck is the part limiting performance in a particular workload. It changes with the game, resolution, settings, and frame-rate target.

How to interpret it

  • At lower resolutions and very high frame rates, CPU limits are more common
  • At higher resolutions and demanding settings, GPU limits are more common
  • One component showing 100% usage is a clue, not a complete diagnosis

There is no universal “perfect CPU/GPU pairing.” Judge the system against the games and display you actually use.

MEMORY / 05

RAM capacity, speed, and channels

RAM holds data that active applications need. Capacity prevents slowdowns from running out of memory; speed and timings can also affect performance.

Before buying

  • Match DDR generation to the motherboard
  • Check the total capacity and number of modules
  • Use the board's memory support list and enable the correct memory profile if stable
  • Check laptop upgrade limits separately; some memory is soldered

Two matched modules often enable dual-channel operation. Four modules do not automatically mean “quad-channel” on mainstream desktops.

STORAGE / 06

SSD types explained

NVMe SSDs use PCI Express and are generally much faster for large transfers than SATA SSDs. Everyday app loading may not scale with headline sequential speeds.

Check compatibility

  • Confirm M.2 length and whether the slot supports NVMe or SATA
  • Check PCIe generation and lane sharing in the motherboard manual
  • Look at endurance, warranty, capacity, and real-world reviews

A reliable midrange SSD is usually a better choice than paying a large premium for a speed number you will rarely notice.

POWER / 07

Choosing a power supply

The PSU converts wall power for the PC. A poor-quality or unsuitable unit can create reliability and safety problems even if its wattage label looks high.

Look beyond watts

  • Independent reviews of the exact model and platform
  • Appropriate capacity for the CPU and GPU with reasonable headroom
  • Correct native GPU connectors and current ATX specification where required
  • Warranty, protections, noise, and regional availability

Do not judge a PSU by brand name alone. A brand can sell both strong and weak models.

COOLING / 08

Cooling and temperatures

Cooling affects noise, sustained performance, and component longevity. Different CPUs and GPUs have different normal operating ranges.

Check the whole setup

  • Compare temperatures under a repeatable workload, not just at idle
  • Check cooler mounting, fan direction, dust, and case airflow
  • Use the exact CPU or GPU model's published thermal limits
  • Watch for thermal throttling, crashes, or unusual fan behavior

A single temperature reading without workload, ambient temperature, and hardware model is not enough to diagnose a problem.

COMPATIBILITY / 09

Motherboards and chipsets

The motherboard connects the parts and determines supported CPUs, memory, expansion, storage, and connectivity.

Verify before ordering

  • CPU socket and exact CPU support list
  • Required BIOS version and whether BIOS flashback is available
  • DDR generation, board size, M.2 slots, USB, Wi-Fi, and expansion
  • Power delivery and cooling for the processor you plan to use

A matching socket does not guarantee every CPU is supported by every board.

COMPATIBILITY / 10

Physical fit: case, GPU, cooler

Parts can be electrically compatible but physically impossible to install together.

Measure these

  • GPU length, thickness, and slot clearance
  • CPU cooler height or radiator size and mounting position
  • Motherboard form factor supported by the case
  • PSU length, cable space, and front radiator clearance

Use the exact case and component manufacturer's dimensions. Product family names can hide different card sizes.

DISPLAY / 11

Resolution and refresh rate

Resolution controls image detail; refresh rate controls how often the display can update. Both affect the GPU workload and the experience.

Match the system to the display

  • 1080p is generally easier to drive than 1440p or 4K
  • Higher refresh rates need higher frame rates to be fully used
  • Check the exact monitor's supported refresh rate over each input
  • Use an appropriate DisplayPort or HDMI cable and port version

A high-refresh monitor does not make the PC render more frames by itself.

BUYING / 12

Inspecting a used gaming PC

Used systems can be good value, but listings often omit important details. Verify the actual machine before paying.

Ask for proof

  • Exact part numbers and clear photos of the system
  • A recent boot and gameplay or stress-test video
  • CPU and GPU load temperatures and any crash history
  • Storage health, included accessories, warranty, and repair history

Arrange high-value purchases with a trusted adult, use buyer-protected payment, and do not pay deposits to unknown sellers.

PRICING / 13

New retail price is not used value

A new-part price reference helps estimate replacement cost. It does not tell you what a used PC will sell for.

Compare like with like

  • Prefer recent completed sales over active asking prices
  • Compare the same CPU/GPU generation and similar condition
  • Account for PSU quality, motherboard, RAM, storage, and warranty
  • Include local demand, shipping, taxes, and platform fees

PCCheck's weekly price references and live retailer offers are research signals, not a used-market appraisal.

LAPTOPS / 14

Laptop GPU names need context

Laptop GPUs with the same name can perform differently because of power limits, cooling, and laptop design.

Check the full configuration

  • GPU power limit or TGP and cooling reviews
  • CPU model and sustained performance
  • RAM channel layout and upgradeability
  • Display resolution, brightness, response, and battery behavior

Do not assume a laptop GPU performs like the desktop GPU with a similar name.

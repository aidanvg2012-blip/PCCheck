How to read these prices

Candidate parts are selected from Pricify’s weekly public US hardware dataset. Before the report is shown, PCCheck checks each selected model against current PCPartPicker retailer listings through API.SH and displays matched retailer offers, availability notes, and the lowest listed price. If a model cannot be matched exactly or has no current offers, it is marked unpriced rather than guessed.

Live lookups are refreshed when the report is generated. Retailer stock, shipping, tax, seller, exact part number, and return policy can still change; verify the checkout page before buying.

What PCCheck checks

Component selection

Matches processor platform, motherboard chipset family, memory generation, storage capacity, and estimated power needs where source data supports it.

Price evidence

Shows tracked price, typical price, retailer count, source, and data date for each matched part.

Compatibility warnings

Calls out BIOS support, physical dimensions, PSU quality, connectors, and other details that still need exact manufacturer checks.

Performance tiers are broad planning guides, not guaranteed FPS results. The builder does not certify a complete system. Always verify exact model numbers and manufacturer compatibility lists.
